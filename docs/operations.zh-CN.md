# CA-Manager 运维手册

> English | [简体中文](operations.md)

## 角色与权限

| 角色 | 能做什么 |
|------|---------|
| 普通用户 User | 提交证书申请（需审批）、生成 PGP 密钥对；**仅能看到自己申请的**证书、请求与个人统计 |
| 操作员 Operator | 全局可读 + 颁发/拒绝/重提交请求、提交 CSR（直接生效）、吊销/取消吊销、发布 CRL、**审批/拒绝普通用户申请** |
| 审计员 Auditor | 全局只读（证书/队列/CRL/**审计日志**），无任何操作权限 |
| 管理员 Admin | 全局可读 + CRL 周期修改、模板启停、用户管理、通知与 LDAP 设置 |

数据可见性由服务端强制校验：普通用户只能打开源于本人已批准申请的证书（否则 403）；仪表盘显示的是个人数据而非全局统计。

用户来源：本地账号（本系统管理）与 AD 域账号（LDAP 绑定验证）。
域账号角色映射：登录后按 `memberOf` 匹配 `ldap.adminGroup` / `ldap.operatorGroup` 设置的组（**默认均为空**——专为 PAM 托管域管密码的场景设计，无需知道 Domain Admins 密码；未匹配的域账号默认成为可申请证书的只读用户）。推荐做法：在 AD 中创建专用组如 `CA-Manager-Admins` / `CA-Manager-Operators` 并填入对应设置项；本地 `admin` 账号保留为应急后门。
配置入口：管理员 → **用户管理** 页下方的 "AD 域集成" 卡片（启用登录、域控地址、NetBIOS 域名、角色映射组、未匹配用户策略）。

## 审批流程（普通用户申请）

只读用户提交的证书申请（粘贴 CSR 与自助生成两种方式）**不会直接提交 CA**：

1. 申请进入 **"证书审批"** 队列（`/approvals`）。自助生成的私钥以**申请人自设的 PFX 密码加密暂存**（AES-256-GCM），服务器不持有明文。
2. 操作员/管理员批准（此时才真正提交 CA）或拒绝（暂存密钥立即销毁）。
3. 颁发后申请人**凭申请时设置的密码一次性下载 PFX**，下载后暂存私钥立即销毁。
4. 提交/批准/拒绝/下载全程审计，审批人可收到 SMTP 通知（需启用邮件通知）。

## 日常操作对照（Web ↔ certutil）

| Web 操作 | 等效命令 |
|---------|---------|
| 证书列表/筛选 | `certutil -view -restrict "..."` |
| 吊销 | `certutil -revoke <serial> <reason>` |
| 颁发 pending | `certutil -resubmit <RequestId>` |
| 拒绝 | `certutil -deny <RequestId>` |
| 发布 CRL | `certutil -CRL` / `certutil -CRL delta` |
| 提交 CSR | `certreq -submit -attrib "CertificateTemplate:X"` |
| 模板启停 | CA 属性 → 策略模块 Templates 列表 |

## 吊销注意

- 除 `certificateHold` 外吊销不可逆；新 CRL 发布后对全网生效（当前 CRL 下次更新时间见"CA 与 CRL"页）
- `certificateHold` 可取消（取消后证书立即恢复有效）；确认不需要时请改用正式原因重新吊销，避免长期 hold
- 危险确认：需在对话框中输入完整序列号
- **过期证书**：证书列表有"已过期"状态筛选（已颁发、超过 NotAfter、尚未吊销）。勾选后点**批量吊销**：跨页保留勾选，所有证书用同一个原因（批量模式不提供 certificateHold），单批最多 2000 张。批量模式不弹逐张序列号确认——勾选本身就是复核环节；随后每个序列号都会向 CA 处理，并汇总吊销数量与每一条失败明细（例如该证书其实已吊销）
- **大规模积压**：同一端点（`POST /api/certificates/batch-revoke`）还支持 `target: "expired"`，无需勾选即吊销全部"已过期且从未吊销"的证书——仅 API 可用，且没有任何排除项。执行前先过一遍"已过期"列表：过期的系统证书（DomainController、CAExchange、KRA…）通常保持原状、不予吊销
- **分页为真服务端分页** —— 3000+ 证书下列表依然流畅；请善用筛选而不是滚动翻页

## CRL 周期

修改后下次发布生效。Delta CRL 设为 0 表示禁用。修改会记录审计。

## 审计

记录项：登录（含失败）/登出/改密/吊销（每张证书一条，批量亦然）/取消吊销/颁发与重新提交（重新提交记为颁发）/拒绝/提交申请（CSR 与自助）/审批提交、批准、拒绝、PFX 与 PGP 一次性下载/发布 CRL/修改 CRL 周期/模板启停/用户增、改、删/PGP 生成与 PGP 记录状态/清单导入、同步、状态与元数据/API Token 创建与吊销/自动化 API 申请与换发/测试邮件与每日通知扫描。
不记录：监听配置变更（HTTP/HTTPS 模式、端口、证书）——此类变更后的服务重启可在 Windows 事件日志中查到。
字段：时间、用户、来源 IP、操作、对象类型、对象、参数摘要、结果。支持按条件查询与 CSV 导出。

## 机器自动化（API Token）

Web 服务器可通过 REST API 免浏览器登录自动申请/更换证书。

**配置（管理员，用户管理页 → "API Tokens" 标签页）：**
1. 每台机器创建一个 Token（以机器名/用途命名）
2. 明文 Token 只显示一次，请立即复制保存——库中只存哈希
3. Token 为操作员权限（可即时颁发、免审批），有效期 1 年

**API 端点**（Bearer 认证，JSON）：

| 端点 | 用途 |
|------|------|
| `POST /api/automation/certificate` | 申请新证书（CN/SAN/密钥算法/模板/PFX 密码）——颁发后直接返回 PFX |
| `POST /api/automation/renew` | 换发：按旧证书序列号读取原参数，签发替换证书。旧证书默认保留 |
| `GET /api/automation/status/{requestId}` | 查询申请状态 |

完整 Windows 示例（申请 + 导入 `LocalMachine\My`）见仓库 `scripts/api-example.ps1`。内置 **API 文档**页（`/apidocs`）提供**全部 REST 端点**的功能分组参考（含可调用的角色、查询参数、请求体与响应示例）及可直接复制的 curl / PHP / Java / PowerShell 示例。

访问规则：

- 三个自动化端点是即时颁发的，因此对 **Viewer 和 Auditor 会话返回 403**；只接受 API Token 或操作员/管理员会话
- Token 在**所有允许操作员的端点上都等同于操作员**——单张与批量吊销、审批、发布 CRL、清单同步……只给可以承担这些操作的机器发 Token，一台机器一个
- 仅限管理员（用户、Token、通知与监听设置）或管理员/审计员（审计日志）的端点对 Token 返回 403
- 用 Token 执行的受审计动作记在 `token:<名称>` 名下；Token 本体不出现在日志中。机器退役时在同一标签页吊销

## 资产清单

**资产清单**页（`/inventory`）统一跟踪 CA 世界里的全部对象：

| 类型 | 来源 |
|------|------|
| 证书 (x509) | 从 CA 颁发记录同步（"同步"按钮，幂等 —— 尽量匹配审批记录的所有人） |
| PGP | 每次生成 PGP 密钥时自动创建追踪记录（只存元数据 —— 永不存密钥材料） |
| 导入证书 | 粘贴第三方证书 PEM/Base64（仅公钥部分） |

每条记录含：负责人、使用人、备注、生命周期状态（`active / expired / revoked / retired`）—— `expired` 按到期日自动计算。普通用户仅见自己的记录；操作员/管理员全局可见；CSV 导出跟随当前筛选。用于回答"这台机器跑的是哪张证书、还剩几天？这份共享文件的 PGP 密钥归谁？"。

## OCSP 在线响应器监控

**系统设置**页（`/system`）有 OCSP 健康卡片（仅管理员），通过 OCSPAdmin COM 接口实时读取 Windows 在线响应器：

- 响应器服务状态（`OCSPSvc`）：Running / 停止 / 未安装
- 每条吊销配置：CA 名称、哈希算法、签名证书颁发者与到期时间
- 告警项：响应器未运行、**未定义任何吊销配置**、签名证书 30 天内到期、吊销数据超过 2 天未更新、`ErrorInformation` 非空

每日汇总邮件包含同样的 OCSP 健康分区。响应器角色本身的部署（安装 ADCS-Online-Cert、在 `ocsp.msc` 中创建吊销配置）属于本系统之外的服务器侧操作 —— 配置创建后监控会自动采集。

## 管理员密码应急重置

忘记 admin 密码时，在该服务器 publish 目录下执行（自包含 exe，服务器无需 .NET；服务可保持运行）：

```powershell
.\CaMgr.Api.exe reset-admin           # 生成临时密码，下次登录强制修改
.\CaMgr.Api.exe reset-admin "New#12345678"   # 或指定密码（至少 8 位）
```

## 服务运维

```powershell
Restart-Service CA-Manager      # 重启（改配置后）
Get-EventLog -LogName Application -Source "CA-Manager" -Newest 20   # 应用日志（Windows 事件日志 + 文件日志）
```

日志同时写入 Windows 事件日志；调试级日志含 COM 调用失败详情（HRESULT）。

## 数据库维护

`publish\data\camgr.db`（SQLite）。审计日志较大时可归档导出后由管理员清理旧记录（当前版本不自动清理）。

## 安全基线建议

1. 生产启用 HTTPS，证书用本 CA 签发
2. 防火墙限制来源为运维网段
3. 域账号配置角色映射后禁用多余本地账号
4. 定期导出审计日志归档
5. `initial-admin-password.txt` 首登后删除

## 邮件通知（SMTP）

管理员 → "通知设置"页配置。支持内网匿名中继与加密连接（明文 / STARTTLS 587 / 隐式 SSL 465）。

- **固定收件人**：接收每日汇总（六类事件：证书到期 / CA 证书到期 / CRL 超期 / 待处理积压 / **清单到期（PGP 与导入证书）** / **OCSP 健康**）
- **申请者通知**：开关开启后，到期证书的申请者邮箱（证书申请时提交的 EMail）会单独收到名下证书清单；机器账户/无邮箱证书自动跳过
- **发送时间**：默认每日 08:00，一天最多一封汇总；"立即执行扫描"可随时手动触发
- **测试**：配置保存后先"发送测试邮件"确认链路，再等定时任务
